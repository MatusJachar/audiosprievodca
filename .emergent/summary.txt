The trajectory documents an iterative and often contentious development process for a multi-language mobile audio tour app. The project began with foundational work, including creating the Expo/FastAPI stack and fixing an initial caching error. The user ultimately updated the English descriptions manually via the newly-built admin panel.

<product_requirements>
The objective is to build and maintain a multi-language audio tour guide mobile app for Spiš Castle.

**Core Features:**
*   **Content Structure:** The app must feature 13 standard, numbered tour stops, followed by 4 separate, individually numbered stops for Legend 1, Legend 2, Legend 3, and Legend 4.
*   **Multi-language Support:** The app supports 8 languages: English, Slovak, German, Polish, Russian, Spanish, Hungarian, and Chinese. All content must be translatable.
*   **Visuals:**
    *   A main background image must be displayed on the welcome/home screen.
    *   Each of the 17 tour stops (13 main + 4 legends) must have a dedicated space for an image, which can be uploaded via the admin panel.
*   **Admin Panel:** A comprehensive, password-protected admin panel accessible from a mobile device is required for all content management. It must allow authorized users to:
    *   Edit the title and full description text for every stop in all supported languages.
    *   Upload/manage a unique image for each of the 17 stops.
    *   Upload/manage the main background image.
    *   Manage or generate audio files for each stop.

**Implementation Status:**
The application is largely functional. It now has 17 distinct tour stops (13 main + 4 legends). A password-protected () admin panel has been implemented, allowing for text and image editing. The background image is now correctly displayed. However, content integrity remains a concern; while the user manually updated the English text, other languages may still have incomplete or incorrect descriptions.
</product_requirements>
