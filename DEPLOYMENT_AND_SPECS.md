## 🚀 Deployment Guide

### Android (Google Play Store)

#### Prerequisites
1. **Google Play Developer Account** - $25 one-time fee
2. **EAS Account** - Free at expo.dev
3. **Keystore** - Auto-generated by EAS

#### Steps
```bash
# 1. Install EAS CLI
npm install -g eas-cli

# 2. Login to Expo
eas login

# 3. Configure project (run in frontend folder)
cd frontend
eas build:configure

# 4. Build for Android (Production)
eas build --platform android --profile production

# 5. Build generates an AAB file (Android App Bundle)
# Download from Expo dashboard after build completes (~20 min)

# 6. Upload to Google Play Console
# - Create new app
# - Upload AAB file
# - Fill store listing (screenshots, description)
# - Submit for review (2-7 days)
```

#### Required Assets for Play Store
- App Icon: 512x512 PNG
- Feature Graphic: 1024x500 PNG
- Screenshots: At least 2 phone screenshots
- Short Description: 80 characters
- Full Description: 4000 characters
- Privacy Policy URL

---

### iOS (Apple App Store)

#### Prerequisites
1. **Apple Developer Account** - $99/year
2. **Mac Computer** (required for final submission)
3. **EAS Account** - Free

#### Steps
```bash
# 1. Build for iOS
eas build --platform ios --profile production

# 2. Build generates an IPA file
# Download from Expo dashboard

# 3. Submit using Transporter app (Mac only)
# Or use EAS Submit:
eas submit --platform ios

# 4. Fill App Store Connect listing
# - Screenshots for all device sizes
# - App description, keywords
# - Submit for review (1-3 days typically)
```

#### Required Assets for App Store
- App Icon: 1024x1024 PNG (no alpha)
- Screenshots: 6.7", 6.5", 5.5" iPhone sizes
- iPad screenshots (if supporting iPad)
- App Preview video (optional)
- Privacy Policy URL
- Support URL
